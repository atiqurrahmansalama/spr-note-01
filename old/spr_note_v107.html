SPR Note — User Guide

A daily progress tracking tool for Hifz teachers. Fill in student details and copy a formatted report instantly.

Step-by-Step Usage
Step 1 — Enter Student Name Type the student's name and saved names will auto-suggest. Tapping a suggestion shows the group name. For new names, use the "Save" button to add them to a group.
Step 2 — Juz & Page Numbers Enter the Juz number and page range. Use mouse scroll or arrow keys to change pages quickly. Use "+" to add another page range within the same Juz. For multiple Juz, use "Add Juz".
Step 3 — Select Session Choose the session type from Sabaq, Sabqi, Manzil, Juz Test, etc. As you add mistake and stuck entries below, the counters update automatically.
Step 4 — Mistake & Stuck Details Add each mistake or stuck point with page and ayah numbers. Press Enter to quickly add a new row. Use "+" to record multiple ayahs on the same page.
Step 5 — Add Comment Type freely or insert a preset from "Saved Messages". Text is added at the cursor position. You can save new comments in Settings → Comments.
Step 6 — Copy Report Tap "Copy Report" to copy the fully formatted report to your clipboard. Paste it directly into WhatsApp, Telegram, or any messaging app.
Tips & Tricks
Scroll to Change NumbersHover over any Juz, page, or ayah input and scroll to change the value quickly.
Keyboard ShortcutsAlt+C = Copy, Alt+R = Reset, Alt+M = Add Mistake, Alt+U = Add Stuck, Alt+D = Dark Mode.
Pin the SidebarOn desktop, click the edge button to pin the sidebar. Collapse to icon-rail to gain more screen space.
Data Saved LocallyStudent names, groups, sessions, and comments are stored in browser local storage. Clearing browser data will remove them.

About SPR Note

A lightweight, offline-capable daily progress reporting tool built specifically for Hifzul Quran teachers.

App Overview
Purpose SPR Note helps Hifz teachers quickly document each student's daily recitation session — tracking Juz, pages, mistakes, and stuck points — and share clean reports instantly with parents or supervisors.
Works Everywhere Runs entirely in the browser — no installation, no account, no internet needed after load. Works equally well on mobile, tablet, and desktop.
Fully Private All student data is stored only in your device's local storage. Nothing is sent to any server. Your information is completely secure and under your control.
