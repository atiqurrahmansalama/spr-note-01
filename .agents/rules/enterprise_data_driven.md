# Enterprise Architecture & Data-Driven Rules

## 1. Zero Hardcoding Policy (সম্পূর্ণ ডাটা-ড্রাইভেন আর্কিটেকচার)
- **কখনোই কোনো প্রপার্টি ম্যানুয়ালি হার্ডকোড করবে না:**
  - কোনো ফর্ম, ড্রপডাউন, ফিল্টার বা কার্ডে `if (isHoliday) color = 'rose' else if (isExam) 'amber'` বা `if (category === 'X') 'Title'` জাতীয় শর্টকাট / ম্যানুয়াল কন্ডিশনাল কোড সম্পূর্ণ নিষিদ্ধ।
  - সমস্ত প্রিসেট, ক্যাটাগরি, রোল, টাইপ ও কালার স্কিমা ডায়নামিক স্টোর / কনফিগারেশন (`localStore`, API, বা সেটিংস/ডেভেলপার টুলস) থেকে ডাটা-ড্রাইভেন পদ্ধতিতে প্রসেস করতে হবে।

## 2. Option Schema & Event Handlers
- **Enriched Option Objects:**
  - ড্রপডাউন বা সিলেক্টরের অপশন লিস্ট তৈরির সময়েই প্রতিটি আইটেমের সঙ্গে তার ডায়নামিক মেটাডাটা (`id`, `value`, `label`, `type`, `category`, `color`, `repeats`, `description` ইত্যাদি) এনক্যাপসুলেট রাখতে হবে।
- **Clean Event Consuming:**
  - `onChange` বা ইভেন্ট হ্যান্ডলার কোনো ম্যানুয়াল `if-else` না চালিয়ে সরাসরি সিলেক্টেড অপশনের প্রোপার্টি থেকে স্টেট আপডেট করবে।

## 3. Dynamic Taxonomy & Extension Safety
- ব্যবহারকারী বা অ্যাডমিন যখনই সেটিংস/ডেভেলপার টুলস থেকে নতুন কোনো ক্যাটাগরি, টাইপ, শিডিউল বা স্কোপ যুক্ত/পরিবর্তন করবেন, সিস্টেম যেন কোনো কোড মডিফিকেশন ছাড়াই স্বয়ংক্রিয়ভাবে ১০০% ডায়নামিক ও নির্ভুলভাবে কাজ করে।
